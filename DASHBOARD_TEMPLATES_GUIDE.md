## How to Use Templates

### Accessing Templates

1. Navigate to the **DASHBOARD TEMPLATES** tab in the main navigation
2. Browse available templates or use filters to narrow down options
3. Click **Apply Template** on any template to instantly add it to your dashboards

### Search & Filter

**Search Bar:**
- Search by template name
- Search by industry
- Search by tags
- Search by description keywords

**Industry Filter:**
- Click an industry tab to view only templates for that sector
- Select "ALL" to view all available templates

**Tag Filter:**
- Click on tags to filter templates by specific features
- Multiple tags can be selected simultaneously
- Click again to deselect a tag

### Applying Templates

When you apply a template:
1. All widgets from the template are added to your dashboard
2. Widgets maintain their configured positions and sizes
3. Data is automatically generated with realistic sample values
4. Unique IDs are assigned to prevent conflicts
5. A success notification confirms the template was applied

### Customizing Applied Templates

After applying a template:
- **Rearrange widgets** by dragging them to new positions
- **Resize widgets** using the grid system
- **Remove widgets** you don't need
- **Add additional widgets** from the console commands
- **Modify widget configurations** (colors, animations, etc.)

## Widget Types in Templates

### Line Chart
Shows trends over time with continuous data points.
- Best for: Time-series data, trends, forecasts
- Example: Daily sales, patient admissions, production output

### Area Chart
Similar to line charts but with filled areas, ideal for comparing multiple series.
- Best for: Multi-series comparisons, stacked data, cumulative values
- Example: Revenue vs. expenses, energy sources over time

### Bar Chart
Displays categorical data with rectangular bars.
- Best for: Comparisons, rankings, category performance
- Example: Quarterly results, department performance, product categories

### Pie/Donut Chart
Shows part-to-whole relationships in a circular format.
- Best for: Distribution, market share, composition
- Example: Traffic sources, portfolio allocation, property types

### Gauge
Displays a single value on a semi-circular scale.
- Best for: KPIs, percentages, scores
- Example: Conversion rate, occupancy rate, efficiency score

### Radar Chart
Multi-dimensional data visualization showing multiple variables.
- Best for: Quality metrics, performance indicators, balanced scorecards
- Example: Customer satisfaction, quality control, engagement metrics

### Metric Cards
Displays key numbers with labels in a grid format.
- Best for: KPIs, quick stats, headline numbers
- Example: Revenue, user count, conversion rate

### Status Board
Shows operational status of various systems or components.
- Best for: System health, availability, operational status
- Example: Server status, facility operations, service availability

## Advanced Features

### Template Combinations

You can apply multiple templates simultaneously:
1. Apply a base template for your primary industry
2. Apply additional templates to add specific widgets
3. All widgets will be added to your dashboard
4. Rearrange as needed to create a custom layout

### Data Refresh

Template widgets use generated sample data. To connect real data:
1. Use the console commands to generate live data
2. Integrate with your APIs or data sources
3. Modify widget configurations to point to real endpoints

### Saving Custom Templates

While custom template creation isn't built-in, you can:
1. Apply a base template
2. Customize widgets extensively
3. Use the dashboard state persistence (automatically saved via useKV)
4. Your customized dashboard will be preserved between sessions

## Best Practices

### Choosing the Right Template

1. **Match your industry** - Start with templates designed for your sector
2. **Consider your audience** - Executive dashboards vs. operational dashboards
3. **Check widget count** - More isn't always better; focus on key metrics
4. **Review tags** - Ensure the template covers your needed metrics

### Template Customization

1. **Start with a base** - Apply a template that's 70-80% of what you need
2. **Remove excess** - Delete widgets that don't apply to your use case
3. **Add specifics** - Use console commands to add custom widgets
4. **Reorganize** - Arrange widgets by priority (top-left = most important)

### Performance Optimization

1. **Limit total widgets** - Keep total widgets under 20 for best performance
2. **Use appropriate chart types** - Don't use radar charts for simple comparisons
3. **Disable animations** - For large datasets, disable animations in chartConfig
4. **Combine metrics** - Use metric cards to consolidate multiple KPIs

### Multi-Dashboard Strategy

1. **Executive Dashboard** - Apply a high-level template (Finance, SaaS)
2. **Operational Dashboard** - Apply a detailed template (Manufacturing, Logistics)
3. **Team Dashboards** - Apply role-specific templates (Marketing, Healthcare)

## Troubleshooting

### Template Not Displaying

- **Check console for errors** - Open browser dev tools
- **Verify data structure** - Ensure widget data matches expected format
- **Refresh the page** - Sometimes state needs to resync

### Widgets Overlapping

- Templates use a 12-column grid system
- If widgets overlap, manually adjust positions
- Each widget has `position: { x, y, w, h }` properties

### Data Not Updating

- Template data is sample/generated data
- To use real data, modify widget data properties
- Integrate with your backend APIs or data sources

### Performance Issues

- Too many animated widgets can slow rendering
- Disable animations: Set `chartConfig.animate: false`
- Reduce widget count or simplify visualizations

## API Reference

### Template Interface

```typescript
interface DashboardTemplate {
  id: string                    // Unique template identifier
  name: string                  // Display name
  industry: IndustryType        // Industry category
  description: string           // Template description
  icon: string                  // Icon identifier
  color: string                 // Primary color (oklch)
  widgets: DashboardWidget[]    // Widget configurations
  tags: string[]                // Searchable tags
}
```

### Utility Functions

```typescript
// Get template by ID
getTemplateById(id: string): DashboardTemplate | undefined

// Get all templates for an industry
getTemplatesByIndustry(industry: IndustryType): DashboardTemplate[]

// Get templates matching specific tags
getTemplatesByTags(tags: string[]): DashboardTemplate[]
```
