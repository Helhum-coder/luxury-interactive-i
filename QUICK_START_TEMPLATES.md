## **5-MINUTE SETUP**

### 1. **Open the App**
Navigate to: **DASHBOARD TEMPLATES** tab

### 2. **Create Your First Protected Template**
- Click **"NEW TEMPLATE"** (green button, top right)
- Fill in:
  - Name: "My Dashboard"
  - Category: Choose one (Work/Personal/Project/Client)
  - Industry: Pick relevant one
  - Tags: Add search tags
- Click **"Create & Save"**

✅ **DONE!** Your template is now **permanently saved**!

### 3. **Create Your Daily Backup**
- Click **💾 Download** button (top right)
- Save file to: `My Documents/Dashboard Backups/`
- Filename: `backup-YYYY-MM-DD.json`

✅ **DONE!** You now have an offline backup!

## **DAILY WORKFLOW**

### Morning (Start of Day):
```
1. Open DASHBOARD TEMPLATES tab
2. Check: "Last backup: [time]" (should be recent)
3. If NOT recent → Click manual backup button (💾)
4. Export daily backup → Save to safe location
```

### During Work:
```
1. Create templates as needed
2. Mark important ones with ❤️ (favorite)
3. Add tags for easy searching
4. Use duplicate (📋) to test changes
```

### End of Day:
```
1. Click "Download All" (💾) button
2. Save backup: backup-2025-01-XX.json
3. Verify file size > 0 KB
4. Close app confidently!
```

## **EMERGENCY RECOVERY**

### 😱 "My templates disappeared!"

**Step 1: Check Filters**
```
1. Clear search box
2. Set Industry → "All Industries"
3. Set Category → "All Categories"  
4. Turn OFF "Favorites" filter
5. Turn OFF "My Templates" filter
```

**Step 2: Force Backup**
```
1. Click manual backup button (💾)
2. Wait for "Auto-backup completed" message
```

**Step 3: Import Last Backup**
```
1. Click Upload button (📤)
2. Select most recent .json backup
3. Templates restored immediately!
```

## **COMMON MISTAKES TO AVOID**

### ❌ **DON'T:**
- Assume auto-backup is enough (always export!)
- Use same filename for all backups
- Store backups only on same computer
- Forget to test imports occasionally
- Delete templates without exporting first
- Ignore "Last backup" timestamp

### ✅ **DO:**
- Export daily (end of day)
- Use dated filenames
- Store backups in 2+ locations
- Test import monthly
- Duplicate before deleting
- Check backup timestamp regularly
