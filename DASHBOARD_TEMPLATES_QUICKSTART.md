## 🔍 Search & Filter Tips

### Search Bar
Type any of these to find templates:
- Industry name (e.g., "healthcare", "finance")
- Feature tags (e.g., "revenue", "patients", "sales")
- Template name or description keywords

### Industry Tabs
Click to filter by industry:
- **ALL** - Show all templates
- **FINANCE, HEALTHCARE, ECOMMERCE**, etc. - Show only that industry

### Tag Badges
Click tags to filter:
- Multiple tags = show templates matching ANY selected tag
- Click again to deselect
- Common tags: `revenue`, `sales`, `efficiency`, `roi`

## ⚡ Quick Commands

Use these console commands alongside templates:

```bash
# Generate additional dashboards
generate dashboard [type]

# See all chart types
demo charts

# Check system
status

# Clear console
clear

# Show available commands
help
```

## 🔧 Customization Guide

After applying a template:

1. **Remove Unwanted Widgets**
   - Delete any widgets that don't apply to your use case

2. **Rearrange Layout**
   - Drag widgets to prioritize important metrics at top-left

3. **Add Custom Widgets**
   - Use console: `generate dashboard [type]`
   - Use console: `demo charts` for all chart types

4. **Adjust Data**
   - Templates use sample data
   - Connect to your real data sources as needed

## 🚨 Troubleshooting

### No Templates Showing?
- **Check filters** - Click "ALL" to reset industry filter
- **Clear search** - Delete text in search box
- **Deselect tags** - Click selected tags to remove filter

### Widget Not Appearing?
- **Refresh page** - State might need to resync
- **Check DASHBOARDS tab** - Widgets appear there after applying
- **Console errors?** - Open browser dev tools to check

### Performance Slow?
- **Too many widgets** - Remove some to improve speed
- **Disable animations** - Modify chartConfig in widget data
- **Simplify charts** - Use simpler chart types
