## 🚀 Quick Start (3 Steps)

### Step 1: Get API Tokens

**GitHub Token:**
1. Visit: https://github.com/settings/tokens/new
2. Name: "LUXE IDE"
3. Check: `repo` and `read:user`
4. Generate and copy token (starts with `ghp_`)

**Linear API Key:**
1. Visit: https://linear.app/settings/api
2. Create key named "LUXE IDE"
3. Copy the key (starts with `lin_api_`)

### Step 2: Open the App

1. Run your app (it should already be running)
2. Click the **"UNIFIED DASHBOARD"** tab in the navigation

### Step 3: Configure

1. Paste your GitHub token
2. Paste your Linear API key
3. Click "Connect Services"
4. Enter your GitHub repository (e.g., `Helhum-coder/my-repo`)
5. Done! 🎉

## 🔧 Troubleshooting

**Nothing shows up?**
- Make sure you entered a repository in the format: `owner/repo`
- Click the refresh button
- Check your tokens are valid

**"Failed to fetch" errors?**
- Verify your tokens have correct permissions
- Make sure you have access to the repository
- Check your internet connection

**Want to start fresh?**
- Click the "RESET ALL" button in the header
- Re-enter your tokens and repository
